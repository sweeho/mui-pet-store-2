# The admin shell

This folder is the layout of [Modernize Free](https://github.com/adminmart/Modernize-Nextjs-Free)
(MIT, AdminMart), vendored from its `package/` folder at commit `948e484ebd3036383bca98a43f58596fd5bb6634` and trimmed to
the shell: the sidebar, the header and the page frame. The dashboards, sample pages, sign-in pages
and charts were left out. Its colours and type are in `design/tokens.mui.json`. The licence is
[LICENSE.md](./LICENSE.md).

Change the shell here like any other code. A project may replace it with Modernize Pro, which Vortex applies from the archive a project admin uploads. `EDITION` records the edition in use, as `modernize:` does in `stack.versions.yaml`; `npm run check-versions` fails when they disagree.
